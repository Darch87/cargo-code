Every service the experiments use. Below: each service with its links, what it connects to, where its keys live, and the steps. No keys are kept here.

Cargo

live The front door: the portfolio, the experiments page and this admin page.
  • Connects to: Loads its code from the cargo-code repo; links out to each tool on GitHub Pages.
  • Passwords: Page passwords live in Cargo, per page.
  • Lock a page: Pages menu, right-click the page, Settings, set a password.
  • Code blocks: no pasting needed. Each page holds one short line, and Claude updates the code in the cargo-code repo.

cargo-code (GitHub)

live The code behind the Cargo site: the homepage collage, the experiments page and this page.
  • Repo: github.com/darch87/cargo-code
  • Cargo lines: Site HTML: one script line loading site.js. Pages: <div data-code="name"></div>, which shows blocks/name.html.
  • Access: The Claude GitHub app must keep access to this repo.
  • Changes show on the site a minute or two after Claude pushes; reload the page.
  • If a page goes blank: check that GitHub Pages is still on for cargo-code (Settings, Pages, Branch: main).

GitHub Pages

live Hosts the tools themselves, from the darch87 account.
  • Sites: brick-holocron (phone: /mobile/), record-bins, arch6171
  • Repos: github.com/darch87
  • Passcodes: Each tool has its own admin and guest passcode, set inside that tool.
  • Update a file: open the repo, open the file, pencil icon, paste the new code, Commit changes.
  • Upload new files: in the repo, Add file, Upload files, drop them in, Commit changes.
  • Wait a minute, then reload the site (a hard refresh if it still looks old).
  • Turn Pages on for a new repo: Settings, Pages, Branch: main, Save.

Google Sheets + Apps Script

live The LEGO sheet and the vinyl sheet hold the data; their Code.gs scripts feed the tools and fetch prices.
  • Connects to: Brick Holocron (LEGO sheet), Den of Discs (vinyl sheet), BrickLink, Discogs, eBay.
  • Keys go in: Each sheet's Apps Script: gear icon (Project Settings), Script properties.
  • Open the sheet, Extensions, Apps Script.
  • Click Code.gs, select all, paste the new code, save.
  • Deploy, Manage deployments, pencil icon, Version: New version, Deploy. This keeps the same web address.
  • To run a job (like setupPrices): pick it in the function dropdown, press Run, allow access if asked.

BrickLink API

live Set prices for Brick Holocron.
  • Connects to: LEGO sheet script.
  • Keys go in: LEGO sheet Script properties.
  • Watch out: The access token's IP must be 0.0.0.0 with mask 0.0.0.0. A 255 mask fails.
  • If prices stop: check the four keys are still in Script properties.
  • Run setupPrices once from Apps Script.

eBay developer

live Price ranges from current listings, for the record store and later Brick Holocron.
  • Connects to: Vinyl sheet script and LEGO sheet script.
  • Keys go in: Script properties, named EBAY_CLIENT_ID and EBAY_CLIENT_SECRET.
  • To change keys: copy the production App ID and Cert ID from the eBay developer site.
  • Replace them in each sheet's Script properties under those two names.
  • Deploy a New version of each script, then Run the price update.

Discogs

live Years, genres and lowest prices for the record store.
  • Connects to: Vinyl sheet script.
  • Keys go in: Vinyl sheet Script properties.
  • Limit: This account only gets a lowest price, so values show as "$X+".

Supabase

testing The database behind the ARCH 6171 course site: student keys, quizzes, progress.
  • Connects to: arch6171 course site.
  • Keys go in: Publishable key: config.js in the arch6171 repo. Admin key: yours only, typed on the site's admin page. The service_role key never goes anywhere.
  • Change the database: Supabase dashboard, SQL Editor, paste the script, Run.
  • Change the site's key: edit config.js in the arch6171 repo and commit.
